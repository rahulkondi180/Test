# Simple Expense Splitter (Ionic + Angular)

A starter Ionic Angular app for splitting shared expenses across a group.

## Features
- Add shared expenses with a name and amount.
- Set number of participants.
- Automatically calculates total and per-person split.
- Shows a running expense list.

## Quick start
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start app:
   ```bash
   npm run start
   ```

## Notes
- This project uses a single standalone Angular component for simplicity.
- Currency is currently formatted in USD.
